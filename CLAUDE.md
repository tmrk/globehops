- Use strict TypeScript and the existing Prettier/CSS token conventions.
- Use `useI18n()` for UI text/formatting and `fmt.city()` for cities; every key belongs in all three typed EN/HU/SV catalogues (missing keys are compile errors). Keep airport proper names untranslated and shared agent/MCP output English.
- Keep pure logic tested in `src/lib/`, `src/state/`, `src/data/` and `src/agent/`; imperative Three.js stays in `src/globe/`.
- Use only openly licensed, documented assets; no proprietary services, keys or backend. The only exception is consent-gated GA4 (`src/analytics.ts`, on `globehops.marki.im` only): never send route data; write the URL via `replaceUrl`/`pushUrl`.
- GlobeHops is 100% static and client-side: Cloudflare Pages deploys the Vite `dist/` as static assets through its native GitHub integration, nothing else. Never add Workers, Pages Functions (`functions/`, `_worker.js`, `_routes.json`), server-side rendering, APIs, databases, bindings or any server runtime; static `public/_headers` and `public/_redirects` are the only host configuration.
- Production is Cloudflare Pages at https://globehops.marki.im/ with the root base `/` (`BASE_PATH` overrides); keep asset URLs base-relative (GitHub Pages is switched off; old `/globehops/…` paths redirect via `public/_redirects`), and preserve URL > remembered route precedence; with neither, the app opens on the globe and its clock (phones: collapsed sheet with Show a flight), not an example route.
- Locale precedence: path > `?lang=` > `globehops:locale` > browser time zone (Budapest/Stockholm country proxy) > browser languages > English. Keep static `/en/`, `/hu/`, `/sv/` pages under the base; ordinary Share links are language-neutral.
- E2E fixtures seed `globehops:locale=en` and Playwright uses `en-GB`; detection specs opt out with `localeChoice: null`. Use a unique `E2E_PORT` for concurrent worktrees.
- Request a render after scene changes; dispose Three.js resources. Preserve synchronous iOS tap-to-focus.
- Globe-synchronised motion runs in the shared frame loop (`src/state/frames.ts`: clock update, then one draw per frame); scale easing by elapsed time; no `backdrop-filter` over the live globe.
- Run lint, unit tests and build; run only the E2E specs affected by the change (`-g`/file filter), in Chromium unless the change is WebKit-sensitive. Keep the full four-project E2E run for broad UI changes or when asked; the CI workflow only runs lint, unit tests, build and three `@smoke` E2E tests (desktop Chromium); Cloudflare Pages runs unit tests and the build before it deploys. Review mobile/desktop screenshots and update docs. Every release bumps the SemVer version (`npm version <level> --no-git-tag-version`) with a matching `## <version> – <date> – <title>` entry at the top of `RECENT_CHANGES.md`; CI tags `v<version>` after Cloudflare's production deploy.
- Never commit `.cache/`; Node scripts, `mcp/` and their imports require erasable TypeScript and `.ts` imports. Cloudflare deploys every push to `main` (including `GITHUB_TOKEN` pushes) and previews other branches/PRs; never re-enable GitHub Pages.
- Read `App.tsx` for journey/timeline orchestration; `lib/{timezone,sun,moon,schedule,flightProgress,timeline,journeyText}.ts` holds time and sky logic; `mcp/` adapts the shared agent modules to local stdio only.
- One UTC `SimulationClock` drives everything through the simulation feed; App must not re-render per frame. Never write `t` during playback (Safari throttling); debounce paused scrubs ≥400 ms.
- Aircraft follow is separate from leg framing: keep north-up and OrbitControls target at the origin, exit on manual camera input, use feed velocity/smoothing and reduced-motion page turns; preference: `globehops:followAircraft`.

- Airport zones come from build-time TBB lookup; offsets and DST come from runtime `Intl`, whose rules can differ and change. Keep links backwards compatible.
- Run `npm run labels:build` (country/marine sources), `npm run places:build` (city exonyms), `npm run timezones:build`, `npm run agent:build` and `npm run mcp` as needed. Never hand-edit generated labels, `city-names.json`, `timezones.json` or `public/agent/*.json`; document place overrides in `data/PLACE_NAMES.md`.
- City exonyms load lazily for hu/sv; locale-aware search reuses the English index until ready. Keep the compatible `globehops:countryNames` key for “Country names” (`globehops:waterNames` inherits it).
- Airspace avoidance (`globehops:avoidAirspace`, default on) must leave great-circle routing and every number exactly unchanged when off. Zones come only from `data/airspace-advisories.json` (sources, dates, operator groups, level limits; see `data/AIRSPACE.md`) built with `npm run airspace:build` from existing Natural Earth polygons; never hand-edit `airspace.json` or invent coordinates.
- Diversion-aware routing (`globehops:diversionRouting`, default on) is ETOPS/EDTO-inspired modelled reach of potential diversion airports, solved in the same A* as airspace (no land/coastline preference); off restores exactly the airspace-only (or great-circle) result. Data comes only from `npm run diversion:build` (OurAirports runways; see `data/DIVERSION.md`); never hand-edit `diversion-airports.json`, never call it an authorisation or an airline's route. Agent/MCP results stay great-circle unless a request opts into `routing`.
- Trips are sequential sections (`PlanState.trip`) separated by explicit stays; never infer stays or layovers from duration, never compare a journey with a later section of its own trip, keep one traveller per trip on one UTC clock and skip stays only in playback (real instants unchanged). Trip links use `2.`–`6.` groups (`N.stay`); documents use `sections`; `leg` counts flights across the (first) trip. The first section keeps single-journey link parameters and globe leg keys.
- Compared trips (`planKind` `compareTrips`): alternatives A–D that are each a trip with the same number of sections (`PlanState.sections`; drafts stored flat, alternative by alternative). Section k is compared with section k; an untimed trip lines up section by section with the timed ones unless its stay was chosen (`lib/compareTrips.ts`); playback skips only stays every traveller shares. Links: `b.2.*`…`d.6.*`; documents: `journeys` with `sections`.
- Keep the ODbL time-zone database and its notices separate from public-domain airports; commit generated time zones with their build record.
- `docs/AGENT_INTEGRATION.md` is for external agents using GlobeHops, not contributors; follow `AGENTS.md` for codebase work.
